# Weather Data Analysis & Automation

A data analytics project using Python, REST API, Pandas, and Power BI to collect, transform, validate, and analyze hourly weather data for 5 Moroccan cities.

## 🛠️ Technologies

* Python
* Pandas
* Requests
* REST API
* CSV
* Power BI

## 📊 Project Overview

The project collects hourly weather data from the Open-Meteo REST API for Marrakech, Casablanca, Rabat, Tangier, and Agadir.

The data is processed and consolidated using Python and Pandas, validated for data quality, and exported to CSV for Power BI analysis.

## 🔄 Data Pipeline

**Open-Meteo API → Python → Pandas → Data Quality Checks → CSV → Power BI**

## 🔍 Data Quality

* 120 hourly records
* 5 Moroccan cities
* 0 missing values
* 0 duplicate rows

## 📈 Power BI Dashboard

The dashboard analyzes:

* Average Temperature
* Highest Temperature
* Average Humidity
* Maximum Wind Speed
* Temperature trends over time
* Comparison between cities
